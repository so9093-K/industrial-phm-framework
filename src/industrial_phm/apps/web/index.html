구간 비교

두 구간의 측정값 분포와 데이터 상태를 저장된 원본 값으로 비교합니다.

무엇을 확인하고 싶나요?

먼저 질문을 고르세요. 현재 설비의 저장된 측정으로 비교 범위와 분석 화면을 준비합니다.

구간 A는 비교할 과거 구간, 구간 B는 살펴볼 구간입니다.

중앙값·분포·상관관계가 무엇인가요?

중앙값은 값을 크기순으로 정렬했을 때 가운데에 있는 값입니다. 분포는 값이 어느 범위에 얼마나 모이는지를 보여줍니다.

상관관계는 같은 시점의 두 값이 함께 움직이는 경향입니다.

주파수 성분(PSD)은 원본 진동이 주파수별로 어떻게 나타나는지 살펴보는 분석입니다. 특정 부품 고장을 확정하지 않습니다.

설비를 선택하면 비교할 측정을 확인합니다.

    데이터 연결 · 등록된 소스

    등록한 CSV·OPC UA 소스와 수신 상태

    소스 등록 현황을 조회합니다.

    연결 상태를 확인하고 해당 설비의 측정 신호로 이동합니다.

    고급 CSV 등록 · 경로·3상 역할 매핑

    PC의 UTF-8 CSV를 직접 선택하거나, 기존처럼 작업공간 내부 CSV 상대 경로를 입력하세요. 직접 선택은 20MiB 이하만 지원하며 소스 등록만 수행합니다. 데이터 수신·DuckLake 적재·분석은 별도 단계입니다.

    파일을 선택하면 첫 행의 컬럼 후보를 확인합니다. 직접 파일을 선택하지 않으면 아래 상대 경로를 입력하세요.

    3상 불평형을 분석할 CSV에만 작성하세요. 전압(V) 또는 전류(A)의 R/S/T를 한 세트로 입력하고, 근거 문장에는 쉼표를 쓰지 마세요.

    등록 전에 CSV와 선택한 열을 점검할 수 있습니다. 점검은 아무것도 저장하지 않습니다.

    파일과 매핑을 설정한 뒤 사전 점검을 실행하세요.

    OPC UA로 설비 연결

    현재는 127.0.0.1의 익명 OPC UA 서버만 연결할 수 있습니다. 변수 탐색은 최대 256개 노드를 조사하며, 결과가 일부만 보이면 객체 후보의 하위 탐색이나 시작 NodeId를 지정하세요.
