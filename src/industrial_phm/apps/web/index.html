실제 설비 연결·고장 진단·안전 판정이 아닙니다. 샘플은 현재 Web의 Supervisor가 살아 있는 동안만 실행되며, 종료해도 별도 샘플 작업공간은 자동 삭제하지 않습니다.

데이터 연결 · 등록된 소스

설정 등록과 실제 수신 근거를 구분합니다. 지원하는 OPC UA 등록·탐색·수집 요청은 이 Web에서 실행합니다.

소스 등록 현황을 조회합니다.

OPC UA는 활성화 후 수집 시작을 요청할 수 있습니다. FILE은 활성화 후 먼저 수신을 검증하고, 명시적 시간 컬럼이 있는 1MiB 이하 CSV의 저장 이력을 별도로 적재할 수 있습니다. Receipt·DuckLake 이력·실시간 연결·분석은 서로 다른 사실입니다. 검증 수신한 FILE은 이력 적재와 별도로 CSV 특징 분석을 명시적으로 실행할 수 있습니다. 특징값은 원본 신호의 물리 의미·건강 상태를 판단하지 않습니다.

로컬 단일 사용자 파일럿입니다. 동일 작업공간의 Supervisor와 별도 preview·수집기를 함께 실행해 쓰기를 경합시키지 마세요. 현재 Web의 변경은 Supervisor IPC 및 writer 잠금 계약을 따릅니다.

CSV 데이터 등록

PC의 UTF-8 CSV를 직접 선택하거나, 기존처럼 작업공간 내부 CSV 상대 경로를 입력하세요. 직접 선택은 1MiB 이하만 지원하며 소스 등록만 수행합니다. 데이터 수신·DuckLake 적재·분석은 별도 단계입니다.

파일을 선택하면 첫 행의 컬럼 후보를 확인합니다. 직접 파일을 선택하지 않으면 아래 상대 경로를 입력하세요.

3상 불평형을 분석할 CSV에만 작성하세요. 전압은 V, 전류는 A로 측정된 값만 지원합니다. R/S/T를 한 세트로 모두 입력하고 각 채널의 단위·상 대응 근거를 직접 확인해야 합니다. 이름만으로 자동 추정하지 않습니다. 근거 문장에는 쉼표를 사용하지 마세요.

등록 전에 현재 CSV와 선택한 열을 실제 데이터 검증기로 확인하세요. 단위·상의 물리적 진실은 자동 확인하지 않습니다. 사전 점검은 수신·이력·분석 기록을 저장하지 않습니다.

파일과 매핑을 설정한 뒤 사전 점검을 실행하세요.

로컬 OPC UA 소스 등록·탐색

현재 파일럿은 127.0.0.1 익명 OPC UA 서버만 허용합니다. 변수 탐색은 최대 256개 노드를 조사합니다. 결과가 일부만 표시되면 객체 후보의 하위 탐색을 선택하거나 시작 NodeId를 명시하세요. 탐색은 수신·등록 근거가 아니며 원격 서버·계정·인증서 설정은 지원하지 않습니다.

등록 후에도 accepted receipt가 확인되기 전에는 모니터링의 관측 데이터가 준비됐다고 표시하지 않습니다. 등록·수집·분석은 서로 다른 단계입니다.

English evidence guide · status controls remain in Korean

What the evidence does and does not establish

This is an English reference, not an English-language operations interface. Live controls, errors and confirmations remain in Korean. Do not use an untranslated control if its meaning is unclear.

  • Registered / active: Configuration or requested lifecycle only. Neither proves a connection nor confirms data receipt.
  • Accepted receipt: Evidence of an accepted read. It is not a DuckLake history commit, continuous live collection or a successful analysis.
  • Stored history: Historical observations with their own original measurement time and quality. Times are shown in KST (UTC+9). They are not current equipment measurements or an assessment of asset health.
  • AnalysisRun / evidence: A persisted analysis result, not a definitive fault diagnosis, alarm, prediction of remaining useful life or proof of safety. No analysis result does not mean a healthy asset.
  • Review acknowledged / closed: Administrative human-review records, not evidence of physical maintenance, fault resolution or safe operation.
  • Missing values / read errors: Unknown is not zero; a failed read does not establish an empty repository. Verify provenance and retry without assuming an unknown command outcome can be repeated safely.
