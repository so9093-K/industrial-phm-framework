# Operations 예시 설정

이 디렉터리는 실제 데이터에 대한 설정 예시를 유지합니다.

- `aihub-boiler-binding.json`: 로컬에 준비한 AI-Hub 239 보일러 계측 기록에 사용할 바인딩 예시입니다. 데이터 본문은 포함되지 않습니다.

프로젝트의 입력은 사용자 CSV 파일·OPC UA 소스·준비한 공개 실측 데이터입니다. 합성 베어링 CSV 번들은 더 이상 배포하지 않습니다.

실행과 데이터 연결은 [Operations 안내](../../apps/README.md) 및 [데이터 준비 안내](../../data/README.md)를 참고하세요.
