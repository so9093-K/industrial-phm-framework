# 실제 현상에서 시작하는 PHM 조사

2026-11-20 · 기준 main `9c695d95`. 공기압축기와 베어링의 저장 실측 기록을 대상으로 구현·확인한 범위다.

## 바꾼 사용자 작업

관측 → 달라진 구간 선택 → 관련 실측 비교 → 필요한 AI 질문·전망·판단으로 이어진다. 모든 분석을 순서대로 통과하거나 두 모델을 반드시 비교하게 하지 않는다.

| 작업 | 구현 |
| --- | --- |
| 변화를 기다리지 않고 경험 | 기존 기록 조회에 빠른 재생·일시정지·이동·전체 기록 복귀를 추가했다. 원본 시각과 측정 번호는 보존한다. |
| 별도 기준 없이 관측 시작 | 최근 관측의 앞쪽 유효 구간을 비교 기준으로 사용한다. 직접 지정한 기준은 고정해서 유지한다. 정상 범위나 고장 판정으로 부르지 않는다. |
| 전압 변화 이해 | 대표 변화 옆에서 같은 구간의 다른 상전압·전류와 전류 수준 비중을 읽는다. 직접 조사하면 관련 신호가 공통 시간축에 열리고 같은 단위끼리만 겹친다. |
| 진동 변화 이해 | RMS 추이와 같은 A/B 구간의 다른 진동 특징·주파수 대역 비중을 나란히 읽는다. 파형 비교는 재생을 멈춘 뒤 실행한다. |
| 질문과 활용 | 전력·진동 모두 선택한 변화에서 AI에 질문한다. 생성 중 후속 질문 입력, 닫기·다시 열기, 답변의 메모 전환을 지원한다. 모델 질문이 아니면 모델 비교 자료를 답변 입력에서 제외한다. |
| 앞으로의 추세 확인 | 기존 조건부 전망을 해당 재생 위치까지의 측정으로 계산한다. 현장 기준까지의 예상 여유를 고장 잔여수명으로 부르지 않는다. |

## 화면과 기존 코드 정리

- 설비 제목·선택 현상·복귀·분석 이동을 하나의 조사 헤더로 묶었다. 재생·상세 조사 중 설비 선택 줄에는 전체 기록의 미래 변화값을 노출하지 않는다.
- 대표 수치 → 그래프와 관련 관측 → 조사 동작 순서로 배치했다. 같은 현상을 설명하는 관련 카드와 모델별 요약의 기본 반복 표시는 제거했다.
- 전력 관련 신호를 각각의 긴 그래프·별도 슬라이더로 나열하던 구조를 같은 단위의 차트 그룹과 공통 구간 선택으로 교체했다. 출처·위치가 같더라도 신호별 측정 의미 ID는 별도로 선택한다.
- 진동 전용 질문 컴포넌트와 맥락 모듈을 공통 변화 조사로 이전했다. 기존 설명 저장·질문·후속 질문·검토 저장 기능을 재사용하며 새 채팅 시스템을 만들지 않았다.
- 바뀐 컴포넌트의 중복 스타일·사용하지 않는 자동 모델/검토 조회를 제거했다. 기존 모델·분포·주파수·전망 분석은 필요한 목적에서 계속 사용할 수 있다.

## 재생의 데이터 범위

빠른 재생은 원본 데이터가 실제 수신 중이라는 뜻이 아니다. 기록 위치마다 그때까지 읽을 수 있는 관측만 사용한다.

- 시간 기록은 `record_until`, 진동은 `acquisition_until`로 입력을 제한한다.
- 집계 전에 범위를 제한한다. 뒤의 큰 값이나 새 운전 수준이 앞 시점의 변화·기준·전망 학습에 섞이지 않는다.
- 신호·기간 비교·주파수 지도·전망·AI 후속 동작에도 같은 제한을 전달한다.
- 계산 중 이전 결과의 조사 동작을 잠근다. 조사·질문·판단을 시작하면 재생을 멈춘다.
- 재생 위치는 저장소 스냅샷과 별개다. 나중에 정정된 원본까지 과거 버전으로 동결하는 기능은 아니다.

OPC UA 연결을 요구하지 않는다. CSV·공개 기록·기존 지속 수신의 저장 경로를 유지한다.

## 실제 사용 확인

운영 작업공간을 읽어 만든 격리 복사본에서 실제 공기압축기 1306·Bearing1_1 기록을 사용했다. 사용자 운영 스택·원본 데이터·LLM 서버·`.other`는 수정하지 않았다.

- 베어링의 98번째 측정까지만 재생했을 때 변화는 72–98번째로 표시됐다. 실제 LLM 답변도 해당 구간의 진동 크기·지속·주파수 변화를 사용했다.
- 생성 중 후속 질문을 입력하고 창을 닫았다 다시 열어, 접수된 답변과 입력 초안이 함께 유지되는 것을 확인했다. 답변을 판단 메모로 옮겨 ‘계속 관찰’로 저장하고 새로고침 후 복원했다.
- 공기압축기 전압 변화에서 S/T상전압과 R상전류를 같은 시각으로 열었다. 세 전압은 한 축, 전류는 별도 축으로 표시됐다. 1440×900·1280×900에서 실제 렌더링을 확인했다.
- 관련 자동 검사에서는 나중에 극단적인 전압·전류·진동을 추가해도 이전 재생 위치의 변화와 전망 입력이 달라지지 않는지 확인한다. 최근 관측의 자동 비교도 수동 기준 없이 변화 구간을 반환하는지 검사한다.

검사 통과를 제품 전체의 완성으로 취급하지 않는다. 실제 현장 수신 검증, 고장 원인 진단, 검증된 RUL 추정은 이번 결과가 아니다. 자동 비교는 앞선 관측과의 차이를 찾는 수단이며, 현장별 중요도·운전 조건을 완전히 대신하지 않는다. 기존 전망 모델의 정확도가 이번 화면 연결로 개선됐다고 주장하지 않는다.
