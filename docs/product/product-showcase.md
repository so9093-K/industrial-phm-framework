# 제품 흐름을 체험하는 시연

처음 보는 사용자가 **무엇이 변했는지 → 어떤 측정이 근거인지 → 무엇을 더 확인할지**를
현재 Svelte UI에서 따라가는 읽기 전용 체험입니다. 별도의 대시보드 UI나 모델 성능 데모를 만들지 않습니다.

## 체험 실행

저장소에서 Node.js 22.12 이상과 npm으로 실행합니다.

```sh
make showcase
```

<http://127.0.0.1:2720/web/>를 열고 위의 체험 순서를 따릅니다. Ctrl-C로 종료합니다.
Python·Docker·데이터셋·모델 서버가 필요하지 않습니다. 일반 Operations는 기존 `make up`을 사용하며
이 안내와 정적 데이터 전송은 `showcase` 빌드 모드에서만 활성화됩니다.

시연 정적 배포물을 만들 때는 아래의 재생성 절차를 사용합니다. 일반 PR에서는 CI가 시연 결과를 자동 재계산하거나 정적 배포물을 업로드하지 않습니다.
생성한 `dist/showcase/`를 일반 HTTP 정적 서버로 제공할 수 있습니다(`/web/` 경로 사용).
예를 들어 Python이 있다면 `python -m http.server --directory dist/showcase 2720`으로 열 수 있습니다.
HTML 파일을 더블클릭하는 `file://` 실행은 지원하지 않습니다.
공개 사이트·계정·도메인에는 아직 배포하지 않았습니다.

## 여섯 단계와 사용자 가치

| 단계 | 해 보는 일 | 확인할 수 있는 것 |
| --- | --- | --- |
| 관측 | 두 합성 펌프를 고른다 | 일정한 기록과 변화 기록, 저장 시각과 검토 대상을 구분 |
| 신호 | 전류/온도와 기록 기간을 바꾼다 | 어떤 값이 함께 변했고 어떤 출처·단위인지 확인 |
| 기준 구간 이탈 | 기록 초반을 기준으로 벗어난 구간을 찾는다 | 중앙값·MAD 기반 기준 구간 이탈, 시점·방향·벗어난 정도 확인 |
| 비교 | 같은 신호의 앞·뒤 기간을 비교한다 | 대표값의 차이, 유효 측정 수·결측·품질을 함께 확인 |
| 추세 예측·RUL | 준비된 1시간 조건에서 `계산하기`를 누른다 | Prophet 추세 예측과 사용자가 정한 종료 기준까지의 조건부 잔여수명 확인 |
| 검토 | 저장된 분석과 메모를 읽고 직접 링크를 다시 연다 | 어떤 입력·분석에 연결한 판단인지 나중에 재확인 |

정적 체험에서는 두 설비, 두 신호, 네 기록 기간, 세 기준 구간, 기본 기간 비교·신호 관계와
기본 전망 및 안내의 13/15 A 전망을 제공합니다. API 요청의 **전체 조건이 일치하는** 저장 결과만 읽습니다.
임의의 기간·기준·예측 설정은 이 배포물에서 새로 계산하지 않습니다. 준비하지 않은 조건은 안내와 함께
실패하며 이전 결과로 바꿔 표시하지 않습니다. 쓰기 요청은 항상 거부합니다.

기준값 등을 직접 바꿔 계산하거나 새 검토를 기록하려면 전체 Operations에서 CSV를 등록하세요.
두 입력 CSV는 체험의 데이터 안내와 [`examples/operations/showcase/`](../../examples/operations/showcase/)에서
내려받을 수 있습니다. 읽기 전용 체험의 `계산하기`는 같은 조건의 실제 저장 결과를 엽니다.

## 데이터와 해석 범위

- 출처: 이 저장소의 [`prepare.py`](../../tools/showcase/prepare.py)가 생성한 합성 시계열.
  외부 원본 데이터나 모델을 재배포하지 않습니다. 저장소의 Apache-2.0 조건을 따릅니다.
- 기록: 2026-10-01 00:00~03:59 UTC, 1분 간격 240행 × 두 설비. 전류(A)·온도(°C)의 단위는
  합성 생성 조건에서 선언했습니다. 실제 계측기의 단위 검증이 아닙니다.
- 순환 펌프 1호기 · 일정한 기록(`demo-pump-stable`): 약 8 A의 일정한 전류와 작은 주기 변화.
  순환 펌프 2호기 · 변화 기록(`demo-pump-change`): 앞 120행 이후 전류에 분당 0.04 A 증가를 더하고 온도도 함께 증가시킵니다.
- 입력은 실제 FILE 수신 검증·DuckLake backfill·통계 분석·사람 검토 명령으로 처리했습니다.
  전망은 실제 Prophet와 기존 전망 API를 사용합니다. 결과 JSON을 손으로 작성하지 않습니다.
- 13 A·15 A는 시연용 임의 기준입니다. 비교의 A 구간을 정상 상태로 검증하지 않았습니다.
  RUL 표시는 사용자 지정 종료 기준까지의 조건부 전망이며, 고장 시각·검증된 잔여수명·고장 확률이 아닙니다.
  별도 학습 RUL 모델은 복원하지 않습니다([ADR-0027](../adr/0027-condition-and-remaining-life-outlook-from-stored-analyses.md)).
- 이 체험의 이상 탐지 단계는 모델이 없는 설비에 쓰는 기준 구간 이탈입니다. 학습 모델(Isolation Forest·LSTM 오토인코더)의
  점수·모델 간 비교·AI 해설은 실제 기록으로 실행하는 `industrial-phm demo xjtu`에서 봅니다([README](../../README.md#이상-탐지에서-rul까지)).

`manifest.json`은 입력 SHA-256, 실제 분석/검토 ID, 생성 코드 해시와 생성 시 기준 커밋을 기록합니다.
개발 중 생성할 수 있으므로 기준 커밋만으로 미커밋 코드를 식별했다고 주장하지 않습니다.
재생성하면 분석 ID·시각·예측 범위의 표본 값이 바뀔 수 있습니다. 입력 생성 조건과 해석 범위는 명시적으로 유지합니다.
세션의 쓰기 토큰과 호스트 개인 경로는 배포하지 않습니다.

## 재생성과 촬영

아래 명령은 Python 개발 환경에서 실행합니다. `export`는 새 임시 작업공간에서만 준비하며
기존 운영 작업공간·데이터·모델을 읽거나 변경하지 않습니다.

```sh
uv sync --locked --extra history --extra forecast --extra opcua
uv pip install --python .venv/bin/python "playwright==1.64.0"
uv run --no-sync playwright install chromium
make frontend
uv run --no-sync python -m tools.showcase.export
npm run --prefix frontend build:showcase
uv run --no-sync python -m tools.showcase.capture
```

캡처 도구는 API 서버 없이 정적 파일만 제공하고 실제 Chromium에서 여섯 단계를 따라갑니다.
PNG는 분석 내용이 보이도록 실제 화면을 스크롤해 촬영합니다. GIF는 촬영 프레임으로 구성한 짧은 흐름이며
WebM은 같은 브라우저 세션 녹화입니다. 그래프나 결과를 이미지에 합성하지 않습니다.
`--no-media`는 파일을 다시 촬영하지 않고 동일한 브라우저 검증을 실행합니다.

입력/근거 계약 테스트는 기본 unit/contract 검사에 포함됩니다. 실제 API 재생성, 브라우저 확인과
캡처 갱신은 체험 기능을 변경하거나 정적 배포물을 제작할 때 별도로 실행합니다.
읽기 전용·알 수 없는 조건·직접 링크 재조회·390px 화면을 검사합니다.
자동 검증 통과가 처음 보는 운영자의 사용성 시험을 대신하지는 않습니다.
공개 체험을 게시하기 전에는 이 배포물을 검토하고 게시할 호스팅 경로를 정해야 합니다.
