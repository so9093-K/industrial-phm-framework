# 데스크톱의 변화 조사 화면

1440×900과 1280×900에서 지금 조사하는 질문과 그래프를 읽고 조작할 수 있도록 구성한다. 화면마다 함께 읽어야 하는 정보를 정하며, 모든 분석에 동일한 본문·설정창 배치를 적용하지 않는다.

- 설비 요약은 대표 변화 한 건의 설명과 비교 수치를 나란히, 그 아래에 전후 그래프를 둔다. 다른 변화는 선택 목록에서 바꾼다. 다음 질문을 고르면 해당 비교 결과 하나가 나타난다.
- 신호의 구간 선택은 그래프 가로축과 같은 폭의 양끝 손잡이를 사용한다. 선택한 구간은 옆에서 조사한다.
- 기간 비교와 관계 분석은 조건을 바꾸려고 그래프를 지나 스크롤할 필요가 없어야 한다.
- 모델 이상 점수는 점수 그래프와 선택한 측정의 주요 값 비교를 나란히 둔다. 전체 특징과 구간 흐름은 필요에 따라 전환한다. 학습하지 않은 운전 조건 등 중요한 해석 제약은 그래프 앞에 남긴다.
- 주파수의 기간 비교는 평균 스펙트럼과 시간별 지도의 가로축 위치·범위를 맞춘다. 지도나 선택 목록에서 측정을 고르면 지도와 해당 측정의 스펙트럼을 나란히 조사한다. 개별 측정 화면에는 기간 평균 요약을 반복하지 않는다. 대역 확대와 실제 측정 번호는 두 보기에서 유지한다.
- 진동 A/B 비교는 같은 특징의 시간 추이와 분포를 나란히 둔다. 신호 관계의 두 기간 그래프도 같은 축으로 비교한다.
- 신호 선택과 전망 기간은 그래프 위에서 바로 조작한다. 3상 분석은 시간 추이와 선택한 시점의 상별 값을 함께 조사한다.

비교 기간·모델 선택·고급 계산 조건은 이름이 있는 설정 창에서 변경한다. 결과가 다른 질문에 답하는 경우에는 모든 표와 설명을 이어 붙이지 않는다. 결과와 조건은 같은 선택을 가리켜야 하며, 조건을 바꾼 후에는 이전 결과를 새 결과처럼 표시하지 않는다.

화면은 PC(1440×900, 1280×900)를 기준으로 구성한다. 좁은 창에서는 한 열로 내려가기만 하면 되고, 휴대폰 폭에 맞춰 PC 배치를 줄이거나 접지 않는다.

## 상태 요약: 무엇이 달라졌는지 이해하는 화면

이 화면에서는 무엇이 언제 얼마나 달라졌는지 파악하고, 더 필요한 비교를 고른다. 판단 기록은 이해를 마친 뒤 선택할 수 있다.

1. **무엇이 얼마나 변했나.** 결론 한 문장(무엇이 · 언제부터 얼마 동안 · 무엇과 비교해 높았는지/낮았는지), 숫자(기록 처음 30% → 변화 구간 → 변화가 기록 끝까지 이어졌으면 마지막 측정), 그래프 하나. 변화가 기록 끝 전에 끝났으면 ‘변화 종료 … · 기록 마지막 …’ 한 줄로 말한다.
2. **다음 조사.** 비교 범위·관련 신호·주파수·모델 중 질문 하나를 골라 해당 사실과 조사 동작을 본다. 요청한 범위·주파수 비교만 조회하며, 숫자는 연결된 분석과 같은 계산에서 가져온다.
   - 범위: 변화 구간 몇 회 중 몇 회가 기록 처음 30% 값의 90%가 있던 범위 밖이었는지 (두 기간 비교)
   - 함께 달라진 것: 같은 구간·측정에서 함께 달라진 신호 한두 개 (신호 관계)
   - 주파수: 진동이면 비중이 가장 크게 바뀐 대역 (주파수 분석)
   - 모델: 이 구간에서 모델마다 몇 회 중 몇 회 기준을 넘었는지. 모델끼리 판단이 갈리거나, 변화가 모델이 학습하지 않은 운전 상태에서 났으면 그 사실을 같은 줄에서 말한다 (이상 징후)
3. **활용.** 판단·메모와 AI 질문은 요청할 때 연다. 창을 닫아도 입력 중인 메모는 유지한다. AI 창을 닫으면 반복 조회를 멈춘다. AI가 제안한 다음 비교는 같은 변화 구간을 연다.

이 기록의 다른 변화는 상단의 선택 목록에서 바꾼다. 분석 방법의 이름·기간 설정·모델별 표·출처와 계산 범위는 주요 변화에 함께 나열하지 않는다. 출처와 계산 범위는 상세에서, 분석 방법은 탭에서 확인한다.

변화 그래프는 두 단으로 그린다: 위는 변화 주변을 확대하고 처음 30%의 중앙값을 점선으로 겹친 그래프, 아래는 기록 전체에서 비교한 처음 30%·변화 구간·확대 범위를 표시한 띠다. 운전 수준별로 판단한 변화는 기록 전체 띠에서 그 수준의 값을 진하게, 모든 운전 상태의 평균을 옅게 그린다. 진동 기록은 측정 회차 축의 그래프 하나로 기록 전체와 변화 구간을 함께 그린다.

데이터 연결은 가져오는 방법(CSV 파일 · 공개 실측 데이터 · OPC UA·작업공간 CSV)을 하나씩 펼친다. 다른 방법을 보는 동안에도 고른 파일과 입력은 유지한다. 측정 이력이 저장된 연결의 다음 단계는 설비 분석 보기다.

## 화면 사이의 같은 기준

상태 요약의 대표 변화가 정한 기준(신호·데이터 출처·운전 수준·기간)을 다른 탭이 기본으로 이어받는다. 두 기간 비교를 탭으로 바로 열면 그 변화의 신호와 운전 수준으로 '기록 처음 30%'(기간 A)와 '변화 구간'(기간 B)을 비교하고, 신호 관계의 결론 문장은 그 운전 수준의 전류 범위에서 고른다. 화면은 그 사실을 한 줄로 밝히며, 사용자가 기간이나 신호를 바꾸면 그 문장을 지운다. 같은 기준이어도 계산 단위가 다르면 숫자가 조금 다를 수 있다(요약은 집계 구간 평균, 관계는 같은 시각의 측정 짝).

진동 기록도 같다. 두 기간 비교·신호 관계·주파수 분석을 탭으로 바로 열면 상태 요약의 대표 진동 변화와 같은 특징, '기록 처음 30%'(기간 A)와 '변화 구간'(기간 B)으로 시작한다. 신호 관계는 그 특징을 같은 측정에서 함께 달라진 특징과 견준다. 관측 현황의 숫자·마지막 값·종료 판단은 상태 요약과 같은 계산에서 온다.

요약의 모델 근거는 이 변화 구간을 분석한 모델만 센다. 모델이 다른 데이터 출처를 분석했으면 넣지 않는다. 절반 이상 기준을 넘은 모델과 절반 미만인 모델이 함께 있으면 판단이 갈렸다고 말한다. 변화가 판단된 운전 상태가 모델 학습 기간에 거의 없었으면(5% 미만), 그 구간의 기준 초과만으로 변화를 확인했다고 보기 어렵다고 말한다. 기록 전체의 횟수와 최근 결과는 이상 징후 탭에서 본다.

누적값과 다른 항목의 값이 복사된 기록은 변화 판단에서 빼므로, '같은 구간에 함께 달라진 신호'와 관계 보기 제안에도 넣지 않는다.

## 주요 변화의 의미

초기 30% 또는 50%와 비교할 때 기준 구간 자체는 이후 변화로 선정하지 않는다. 전체 분포 탐색은 별도의 명시적 선택이다. 높음·낮음은 비교 기준에 대한 값의 차이이며 시간 방향의 추세나 고장 판정이 아니다.

대표 변화는 해당 구간에 최소 세 개의 집계 값이 있고 대표값도 기존 비교 범위를 벗어날 때 선정한다. 한두 번의 측정 이탈은 원본 신호와 기록 변화 찾기에서 확인할 수 있다. 같은 출처·위치·신호·측정 의미의 여러 구간은 요약에서 한 건으로 묶으며, 서로 다른 출처나 의미를 합치지 않는다.

비교 구간의 변동 폭 대비 대표값 차이를 함께 표시한다. 일정했던 기준에는 배율을 만들지 않는다. 작은 퍼센트 차이만으로 중요하지 않다고 단정하지 않으며, 서로 다른 물리량의 절대 차이를 순위로 비교하지 않는다.

운전 수준을 나눌 수 있는 기록은 요약과 기록 변화 찾기에서 같은 수준의 기준을 사용한다. 마지막 측정·수신 확인 항목은 과거 전체 기록의 주요 변화와 구분해 이름 붙인다.

CSV 단위는 기본 단계에서 확인한다. 운전 수준에 쓸 전류 열과 A 단위는 사용자가 직접 확인하며, 이 선택으로 R/S/T 상을 만들어내지 않는다. 내부 식별자는 조사 링크에 그대로 유지하고 등록된 파일 이름과 사용자 표현을 먼저 보여준다.


## 관측 현황: 먼저 볼 설비를 고르는 화면

이 화면을 여는 사람은 여러 설비의 기록을 맡은 설비 담당자이고, 여기서 정하는 일은 어느 설비의 상태 요약을 먼저 열지다. 한 행이 한 설비이며, 설비끼리 견줄 사실만 같은 자리에 둔다.

1. **주요 변화.** 상태 요약이 먼저 보여 주는 변화와 같은 결론 한 문장과 숫자(기록 처음 30% → 변화 구간 → 기록 끝까지 이어졌으면 마지막 값). 기록 끝 전에 끝난 변화는 ‘변화 종료 … · 기록 마지막 …’ 한 줄로 말한다. 숫자와 종료 판단은 상태 요약과 같은 계산이다(마지막 값은 진동이면 마지막 측정, 시계열이면 마지막 구간 평균). 표에는 숫자만 두고 차이·배율 설명은 상태 요약에서 읽는다.
2. **추이.** 같은 신호의 그래프 하나. 가까운 전후 측정은 포함하되 멀리 떨어진 기록을 끌어와 측정 공백을 잇지 않는다.
3. **모델·검토.** ‘모델 · 최근 측정 기준 초과(또는 이하) · 모델 이름’, ‘검토 · 마지막 판단 · 날짜’ 또는 ‘검토 · 기록 없음’. 수신이 끊겼거나 모델이 입력을 처리하지 못했으면 그 사실을 한 줄씩 더하고, 운영 확인 항목은 ‘운영 · 확인 항목 n건’에서 아래 묶음을 연다.

행 전체가 그 설비의 상태 요약으로 가는 링크 하나다. 원본 신호·점수 추이·두 기간 비교는 상태 요약의 변화 근거에서 연다. 계산을 기다리거나 실패한 행만 원본 신호로 바로 가는 링크를 둔다. 정렬은 확인 항목이 우선이고(모델 기준 초과·기록 끝 변화 → 입력 거부·모델 실행 불가 → 최근 기준 초과·수신 없음 → 분석 대기), 같으면 확인 항목 수, 그다음 목록 순서다. 운전 수준 비율·제외된 신호·데이터 출처는 표에 두지 않고 상태 요약의 계산 범위에서 본다. 모델·수신 상태를 다 읽지 못했으면 표 위에 한 줄로 밝히고, 읽지 못한 사실을 ‘없음’으로 쓰지 않는다. 설비가 하나여도 같은 표를 쓴다.

준비된 공개 베어링 파일은 현재 작업공간에 등록된 설비와 구별한다. 베어링 기록이 아직 없으면 기존 가져오기 화면의 베어링 목록으로 바로 안내하고, 등록 후에는 이 안내를 반복하지 않는다. 보기 전용이면 실행을 약속하는 가져오기 대신 목록 보기로 안내하고, 가져올 수 없는 이유를 미리 알린다. 임의의 설비·건강 점수·예측 수치를 표시하지 않는다.

상태 요약에서 다른 변화를 고르면 그 신호·출처·위치·운전 수준·비교 기간을 주소에 유지한다. 진동도 선택한 특징과 측정 구간을 이어받는다. 탭을 옮겼다 돌아오거나 새로고침해도 기록의 순번이 아닌 같은 변화의 신호와 기간으로 복원한다.
