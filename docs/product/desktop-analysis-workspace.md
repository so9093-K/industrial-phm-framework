# 데스크톱의 변화 조사 화면

1440×900과 1280×900에서 결과와 조작을 함께 볼 수 있도록 구성한다. 넓은 왼쪽 영역은 대표 수치·그래프·선택 결과를, 좁은 오른쪽 영역은 신호·기간·비교 조건과 후속 조사를 맡는다. 좁은 창에서는 결과 다음에 조작을 배치한다.

- 설비 요약은 대표 변화 한 건을 크게 표시하고 다른 변화는 옆 목록에서 선택한다.
- 신호의 구간 선택은 그래프 가로축과 같은 폭의 양끝 손잡이를 사용한다. 선택한 구간은 옆에서 조사한다.
- 기간 비교와 관계 분석은 조건을 바꾸려고 그래프를 지나 스크롤할 필요가 없어야 한다.
- 모델 점수 그래프가 모델별 비교표보다 먼저 보인다. 주파수 결과의 설명·계산과 전망 계산은 유지한다.

## 주요 변화의 의미

초기 30% 또는 50%와 비교할 때 기준 구간 자체는 이후 변화로 선정하지 않는다. 전체 분포 탐색은 별도의 명시적 선택이다. 높음·낮음은 비교 기준에 대한 값의 차이이며 시간 방향의 추세나 고장 판정이 아니다.

대표 변화는 해당 구간에 최소 세 개의 집계 값이 있고 대표값도 기존 비교 범위를 벗어날 때 선정한다. 한두 번의 측정 이탈은 원본 신호와 기록 변화 찾기에서 확인할 수 있다. 같은 출처·위치·신호·측정 의미의 여러 구간은 요약에서 한 건으로 묶으며, 서로 다른 출처나 의미를 합치지 않는다.

비교 구간의 변동 폭 대비 대표값 차이를 함께 표시한다. 일정했던 기준에는 배율을 만들지 않는다. 작은 퍼센트 차이만으로 중요하지 않다고 단정하지 않으며, 서로 다른 물리량의 절대 차이를 순위로 비교하지 않는다.

운전 수준을 나눌 수 있는 기록은 요약과 기록 변화 찾기에서 같은 수준의 기준을 사용한다. 마지막 측정·수신 확인 항목은 과거 전체 기록의 주요 변화와 구분해 이름 붙인다.

CSV 단위는 기본 단계에서 확인한다. 운전 수준에 쓸 전류 열과 A 단위는 사용자가 직접 확인하며, 이 선택으로 R/S/T 상을 만들어내지 않는다. 내부 식별자는 조사 링크에 그대로 유지하고 등록된 파일 이름과 사용자 표현을 먼저 보여준다.
