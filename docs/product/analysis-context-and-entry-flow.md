# 같은 기록으로 이어지는 분석 경험

설비 요약의 주요 변화 → 원본 신호 → 기간 비교·기준 이탈·전망 → 판단·메모는 같은 출처·측정 위치·측정 의미를 가리킨다. 신호 이름이 같다는 이유로 기록을 합치거나 더 많은 관측을 가진 다른 출처로 바꾸지 않는다.

- 원본 그래프의 선택 구간에서 만드는 링크는 화면 전체 필터가 아니라 해당 그래프의 출처·위치·측정 의미를 전달한다. 분석 간 링크와 같은 설비의 탭 이동은 선택한 기록 및 조사 구간을 유지한다. 신호를 직접 바꾸면 이전 신호의 기록 키와 측정 의미 선택을 해제하고 출처·위치는 유지한다. 다른 설비를 고르면 이전 설비의 선택을 넘기지 않는다.
- 기준 이탈과 전망은 `record_key` 또는 `monitor_source/monitor_point/monitor_interpretation`으로 기록을 선택한다. 빈 `monitor_point`는 위치 미지정 기록만을 뜻한다. 명시한 기록이 없으면 조회 실패로 알리고, 사용자가 다른 기록을 선택하기 전까지 대체하지 않는다. 출처 제한으로 결과가 없더라도 원본 신호·기준 이탈·신호 관계·두 기간 비교에서 제한을 명시적으로 해제할 수 있다. 두 기간 비교에서는 선택 신호와 A/B 기간을 그대로 유지한다.
- 전망의 기간 선택·수치 예측·조건 도달 계산·AI 해설·저장 검토·재검증은 같은 기록 키를 사용한다. 결과 제목 근처에 실제 분석한 출처·위치를 표시한다. 넘겨받은 조사 구간은 맥락으로 표시하며 임의로 전망 학습 기간으로 적용하지 않는다.
- 기록 키가 없던 이전 전망 검토는 같은 출처·위치의 기록이 유일하고 단위 및 원래 계산 근거가 일치할 때 기존 판단을 복원한다. 모호한 다른 측정 의미의 검토를 자동으로 연결하지 않는다. 기존 저장 결과 자체는 보존한다.
- 변화 카드의 큰 수치는 기존 계산의 기준 대표값 → 변화 구간 대표값이다. 작은 추이는 해당 기록의 실제 집계값을 요약한 것이며 음영은 발견한 변화 구간이다. 요약 전 집계에서 원본 그래프와 같은 기준으로 측정 공백을 확인하며, 공백이 있으면 선을 끊는다. 표시 점을 생략했다는 이유만으로 정상 구간을 끊지는 않는다. 기존 추이 값 형식은 유지하고 연결 여부는 별도로 전달한다. 표시용 추이는 검토 식별자를 바꾸지 않는다. `변화 구간 조사`와 `판단·메모`를 먼저 제공하고 직전 기간·다른 신호 비교는 펼쳐서 확인한다.
- CSV 등록은 미리보기·시간대·설비를 확인한 뒤 `확인하고 저장하기` 한 번으로 서버 점검과 기존 등록·수집·이력 저장을 실행한다. 저장·제외할 숫자 열의 개수와 이름은 접힌 상태에도 표시하고, 12개 한도로 제외된 열은 명시한다. 저장 대상 확인·변경에서 바로 선택을 바꿀 수 있다. 표시명·단위·통계·처리 내역은 상세 영역에서 확인한다. 시간대 확인, 서버 검증, 중복 방지와 실패 후 재개는 유지한다. 완료 후 주요 변화로 이동할 수 있다.
- 설비 목록은 기존 확인 건수 정렬을 유지하면서 대표 확인 이유와 해당 근거를 설비명 옆에 보여준다. 확인에 실패한 이전 사유를 현재 결과처럼 남기지 않는다.

새 분석 알고리즘·차트 라이브러리·정비 기록 시스템은 추가하지 않는다.

## 주요 조작과 정보 순서

- 전망의 신호·예측 기간 또는 측정 횟수·계산하기는 항상 보이는 주요 조작이다. 민감도·학습 범위·계절성은 고급 모델 설정에 둔다. 조건이 바뀌면 이전 결과를 지우고 새 계산을 기다리므로 선택한 기간과 표시한 결과를 혼동하지 않는다. 그래프 뒤에서 모델 시작 수준 차이와 검증 조건을 확인할 수 있다.
- 변화 구간이 없으면 원본 신호 추세를 먼저 제공한다. 같은 기록의 마지막 집계값·집계값 범위를 표시하며, 이를 설비의 정상·안정 판정으로 표현하지 않는다.
- 관측 현황은 설비 목록과 대표 사유를 먼저 보여주고 검토함 진입·운영 상세를 뒤에 둔다. 상세가 접혀 있어도 목록의 확인 이유는 기존 조회로 갱신하며 사유 링크는 해당 상세를 펼친다.
- 전망 검토의 주 동작은 판단 저장이다. 판단을 아직 남기지 않을 때는 보조 동작인 결과만 저장을 사용한다. 저장·복원 계약은 동일하다.
- 공개 데이터가 없을 때도 첫 화면에서 준비 안내로 이동할 수 있다. data/README.md의 기존 준비 방법과 원본 폴더 위치를 안내하고 준비 후 다시 찾기를 제공한다.

## 사용자에게 보이는 표현

- 분석 이름은 행동을 설명한다. `달라진 구간 찾기`에서 비교 기준 기간과 실제 계산 범위를 안내한다. 내부 baseline 식별자와 계산은 유지한다.
- 시간 구간 평균은 `구간 평균`으로 설명한다. 최근 원시 측정값으로 오해할 수 있는 단순한 `최근값`으로 바꾸지 않는다.
- 진동 데이터의 acquisition은 화면에서 `측정`으로 표현한다. 데이터 출처·측정 위치·단위는 결과를 구별하는 데 필요하므로 보존하고, 해석 식별자와 버전은 기술 상세에서 확인한다.
- 검토 진입은 저장한 검토를 이어가는 행동으로 설명한다. 다른 사람에게 업무를 전달하는 기능처럼 표현하지 않는다.
