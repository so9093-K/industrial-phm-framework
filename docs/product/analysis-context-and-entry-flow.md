# 같은 기록으로 이어지는 분석 경험

설비 요약의 주요 변화 → 원본 신호 → 기간 비교·기준 이탈·전망 → 판단·메모는 같은 출처·측정 위치·측정 의미를 가리킨다. 신호 이름이 같다는 이유로 기록을 합치거나 더 많은 관측을 가진 다른 출처로 바꾸지 않는다.

- 분석 간 링크와 같은 설비의 탭 이동은 선택한 기록 및 조사 구간을 유지한다. 신호를 직접 바꾸면 이전 신호의 기록 키와 측정 의미 선택을 해제하고 출처·위치는 유지한다. 다른 설비를 고르면 이전 설비의 선택을 넘기지 않는다.
- 기준 이탈과 전망은 `record_key` 또는 `monitor_source/monitor_point/monitor_interpretation`으로 기록을 선택한다. 빈 `monitor_point`는 위치 미지정 기록만을 뜻한다. 명시한 기록이 없으면 조회 실패로 알리고, 사용자가 다른 기록을 선택하기 전까지 대체하지 않는다.
- 전망의 기간 선택·수치 예측·조건 도달 계산·AI 해설·저장 검토·재검증은 같은 기록 키를 사용한다. 결과 제목 근처에 실제 분석한 출처·위치를 표시한다. 넘겨받은 조사 구간은 맥락으로 표시하며 임의로 전망 학습 기간으로 적용하지 않는다.
- 기록 키가 없던 이전 전망 검토는 같은 출처·위치의 기록이 유일하고 단위 및 원래 계산 근거가 일치할 때 기존 판단을 복원한다. 모호한 다른 측정 의미의 검토를 자동으로 연결하지 않는다. 기존 저장 결과 자체는 보존한다.
- 변화 카드의 큰 수치는 기존 계산의 기준 대표값 → 변화 구간 대표값이다. 작은 추이는 해당 기록의 실제 집계값을 요약한 것이며 음영은 발견한 변화 구간이다. 요약 전 집계에서 원본 그래프와 같은 기준으로 측정 공백을 확인하며, 공백이 있으면 선을 끊는다. 표시 점을 생략했다는 이유만으로 정상 구간을 끊지는 않는다. 기존 추이 값 형식은 유지하고 연결 여부는 별도로 전달한다. 표시용 추이는 검토 식별자를 바꾸지 않는다. `변화 구간 조사`와 `판단·메모`를 먼저 제공하고 직전 기간·다른 신호 비교는 펼쳐서 확인한다.
- CSV 등록은 미리보기·시간대·설비를 확인한 뒤 `확인하고 저장하기` 한 번으로 서버 점검과 기존 등록·수집·이력 저장을 실행한다. 저장·제외할 숫자 열의 개수와 이름은 접힌 상태에도 표시하고, 12개 한도로 제외된 열은 명시한다. 저장 대상 확인·변경에서 바로 선택을 바꿀 수 있다. 표시명·단위·통계·처리 내역은 상세 영역에서 확인한다. 시간대 확인, 서버 검증, 중복 방지와 실패 후 재개는 유지한다. 완료 후 주요 변화로 이동할 수 있다.
- 설비 목록은 기존 확인 건수 정렬을 유지하면서 대표 확인 이유와 해당 근거를 설비명 옆에 보여준다. 확인에 실패한 이전 사유를 현재 결과처럼 남기지 않는다.

새 분석 알고리즘·차트 라이브러리·정비 기록 시스템은 추가하지 않는다.
