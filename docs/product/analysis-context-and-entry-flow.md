# 같은 기록으로 이어지는 분석 경험

설비 요약의 주요 변화 → 원본 신호 → 기간 비교·기준 이탈·전망 → 판단·메모는 같은 출처·측정 위치·측정 의미를 가리킨다. 신호 이름이 같다는 이유로 기록을 합치거나 더 많은 관측을 가진 다른 출처로 바꾸지 않는다.

- 원본 그래프의 선택 구간에서 만드는 링크는 화면 전체 필터가 아니라 해당 그래프의 출처·위치·측정 의미를 전달한다. 분석 간 링크와 같은 설비의 탭 이동은 선택한 기록 및 조사 구간을 유지한다. 신호를 직접 바꾸면 이전 신호의 기록 키와 측정 의미 선택을 해제하고 출처·위치는 유지한다. 다른 설비를 고르면 이전 설비의 선택을 넘기지 않는다.
- 기준 이탈과 전망은 `record_key` 또는 `monitor_source/monitor_point/monitor_interpretation`으로 기록을 선택한다. 빈 `monitor_point`는 위치 미지정 기록만을 뜻한다. 명시한 기록이 없으면 조회 실패로 알리고, 사용자가 다른 기록을 선택하기 전까지 대체하지 않는다. 출처 제한으로 결과가 없더라도 원본 신호·기준 이탈·신호 관계·두 기간 비교에서 제한을 명시적으로 해제할 수 있다. 두 기간 비교에서는 선택 신호와 A/B 기간을 그대로 유지한다.
- 전망의 기간 선택·수치 예측·조건 도달 계산·AI 해설·저장 검토·재검증은 같은 기록 키를 사용한다. 결과 제목 근처에 실제 분석한 출처·위치를 표시한다. 넘겨받은 조사 구간은 맥락으로 표시하며 임의로 전망 학습 기간으로 적용하지 않는다.
- 기록 키가 없던 이전 전망 검토는 같은 출처·위치의 기록이 유일하고 단위 및 원래 계산 근거가 일치할 때 기존 판단을 복원한다. 모호한 다른 측정 의미의 검토를 자동으로 연결하지 않는다. 기존 저장 결과 자체는 보존한다.
- 변화 카드의 큰 수치는 기존 계산의 기준 대표값 → 변화 구간 대표값이다. 작은 추이는 해당 기록의 실제 집계값을 요약한 것이며 음영은 발견한 변화 구간이다. 요약 전 집계에서 원본 그래프와 같은 기준으로 측정 공백을 확인하며, 공백이 있으면 선을 끊는다. 표시 점을 생략했다는 이유만으로 정상 구간을 끊지는 않는다. 기존 추이 값 형식은 유지하고 연결 여부는 별도로 전달한다. 표시용 추이는 검토 식별자를 바꾸지 않는다. `변화 구간 조사`와 `판단·메모`를 먼저 제공하고 직전 기간·다른 신호 비교는 펼쳐서 확인한다.
- CSV 등록은 미리보기·시간대·설비를 확인한 뒤 `확인하고 저장하기` 한 번으로 서버 점검과 기존 등록·수집·이력 저장을 실행한다. 저장·제외할 숫자 열의 개수와 이름은 접힌 상태에도 표시하고, 12개 한도로 제외된 열은 명시한다. 저장 대상 확인·변경에서 바로 선택을 바꿀 수 있다. 표시명·단위·통계·처리 내역은 상세 영역에서 확인한다. 시간대 확인, 서버 검증, 중복 방지와 실패 후 재개는 유지한다. 완료 후 주요 변화로 이동할 수 있다.
- 설비 목록은 확인된 대표 사유의 기존 중요도 순서로 정렬하고, 같은 중요도에서는 확인 건수와 원래 목록 순서를 유지한다. 대표 확인 이유와 해당 근거를 설비명 옆에 보여준다. 대표 사유가 없는 서버 확인 항목은 분석 대기와 같은 정렬 그룹에서 건수로 비교한다. 사유가 없다는 이유로 대기 항목보다 항상 뒤로 보내거나 정상 상태로 판단하지 않는다. 확인에 실패한 이전 사유를 현재 결과처럼 남기지 않는다.

새 분석 알고리즘·차트 라이브러리·정비 기록 시스템은 추가하지 않는다.

## 주요 조작과 정보 순서

- 전망의 신호·예측 기간 또는 측정 횟수·계산하기는 항상 보이는 주요 조작이다. 민감도·학습 범위·계절성은 고급 모델 설정에 둔다. 조건이 바뀌면 이전 결과를 지우고 새 계산을 기다리므로 선택한 기간과 표시한 결과를 혼동하지 않는다. 그래프 뒤에서 모델 시작 수준 차이와 검증 조건을 확인할 수 있다.
- 변화 구간이 없으면 원본 신호 추세를 먼저 제공한다. 같은 기록의 마지막 집계값·집계값 범위를 표시하며, 이를 설비의 정상·안정 판정으로 표현하지 않는다.
- 관측 현황은 설비 목록과 대표 사유를 먼저 보여주고 검토함 진입·운영 상세를 뒤에 둔다. 상세가 접혀 있어도 목록의 확인 이유는 기존 조회로 갱신하며 사유 링크는 해당 상세를 펼친다.
- 전망 검토의 주 동작은 판단 저장이다. 판단을 아직 남기지 않을 때는 보조 동작인 결과만 저장을 사용한다. 저장·복원 계약은 동일하다.
- 공개 데이터가 없을 때도 첫 화면에서 준비 안내로 이동할 수 있다. data/README.md의 기존 준비 방법과 원본 폴더 위치를 안내하고 준비 후 다시 찾기를 제공한다.

## 사용자에게 보이는 표현

- 분석 이름은 행동을 설명한다. `달라진 구간 찾기`에서 비교 기준 기간과 실제 계산 범위를 안내한다. 내부 baseline 식별자와 계산은 유지한다.
- 시간 구간 평균은 `구간 평균`으로 설명한다. 최근 원시 측정값으로 오해할 수 있는 단순한 `최근값`으로 바꾸지 않는다.
- 진동 데이터의 acquisition은 화면에서 `측정`으로 표현한다. 데이터 출처·측정 위치·단위는 결과를 구별하는 데 필요하므로 보존하고, 해석 식별자와 버전은 기술 상세에서 확인한다.
- 검토 진입은 저장한 검토를 이어가는 행동으로 설명한다. 다른 사람에게 업무를 전달하는 기능처럼 표현하지 않는다.

## 저장 기록의 시점과 조사 동작

- 관측 현황의 현재 시각은 목록을 확인한 시각이다. 각 카드에는 저장 기록 여부와 실제 측정 시각을 따로 표시한다. `stored-history`는 과거 저장 기록으로 안내하며, 현재 수신 중이라는 뜻으로 표시하지 않는다. 진동 기록에 측정 시각이 없으면 측정 회차만 표시한다.
- 대표 변화는 신호명·변화 방향과 비교 범위·변화 시작을 먼저 보여준다. 분석한 마지막 측정 시각은 해당 변화 API의 `last_at`을 사용한다. 다른 신호의 더 새로운 시각이나 파일을 읽은 시각으로 대신하지 않는다.
- 변화 구간 조사하기는 원본 신호 그래프로 바로 연결한다. 해당 출처·위치·측정 항목·기록 키와 변화 구간을 유지한다. 조사 구간은 주소에 남겨 화면 재생성과 새로고침 뒤에도 복원한다. 31일을 넘는 변화는 시작 구간을 열며 버튼에서도 이를 알린다. 마지막 측정 시각을 모르면 구간을 추정하지 않고 해당 신호 기록을 연다.
- 공개 실측 데이터명은 짧게 표시한다. 제공 기관의 Training/Validation 분류는 모델 학습 여부와 구분한다. 원본 지문·식별자·미지정 측정 위치는 데이터 상세에서 확인하며, 여러 원본을 선택·비교할 때는 원본 분류와 버전을 구별할 수 있게 유지한다.

## 현상을 중심으로 읽는 결과

- 관측 현황의 기본 보기는 설비 종류와 무관하게 전체 중요도 순서를 유지한다. 종류별 묶음은 명시적으로 선택하며, 운전 비율과 긴 확인 설명은 행의 상세에서 읽는다. 주요 변화·최근 측정·대표 사유와 조사 동작은 기본 행에 유지한다.
- 설비 요약은 주요 변화의 값·기간·추세·조사 동작을 먼저 보여준다. 운전 수준 전체의 분포 표·시간 그래프와 분석 범위는 결과 뒤의 상세에서 확인한다. 변화 판단에서 제외한 데이터의 제약은 결과 앞에 남긴다.
- 변화의 운전 맥락은 해당 변화에 연결된 operation 키와 band만 사용한다. 같은 수준의 비교를 이미 계산한 경우와 운전 비율만 함께 확인할 수 있는 경우를 구분한다. 전류 수준이 같다고 실제 부하나 원인이 같다고 단정하지 않는다. 기간 비교 링크는 기존 기록·위치·측정 항목·A/B 기간·운전 수준을 보존한다. 관계 분석은 두 기간의 전체 운전 수준을 다루므로 해당 범위를 동작 이름에 명시하고 지원하지 않는 운전 수준 필터를 넘기지 않는다.
- 같은 입력 범위에서 출력 분포가 달라진 관계 결과는 계수 설명보다 먼저 표시한다. 상관계수를 계산할 수 없어도 기존 범위별 측정 짝 요건을 충족하면 값의 차이는 표시한다. 상관계수와 상세 표는 함께 확인할 수 있고, 인과관계로 해석하지 않도록 기존 계산 조건을 유지한다.
- 전망의 핵심 결과는 그래프 앞에서 한 번 보여준다. 그래프 아래에는 상세 해석을 남기고 판단 보류 경고는 결과 상단에 유지한다. 첫 방문의 분석 목록은 등록 동작 뒤의 접힌 안내로 제공한다.

## 분석의 역할과 선택

- 주요 변화는 자동으로 고른 조사 출발점, 기록 변화 찾기는 한 신호를 기준 구간과 견주는 탐색, 모델 이상 점수는 학습한 모델이 측정의 특이성을 평가한 결과다. 세 가지를 같은 점수나 고장 판정으로 읽게 하지 않는다. 변화 카드의 기본 맥락과 동작은 한 번만 보여주고, 상세에는 비교 범위와 관련 신호 전체를 남긴다.
- 기록 변화 찾기의 초기 30%·50%는 이후 기록을 초반과 견준다. 전체 분포 선택은 전체에서 다른 구간을 찾으므로 전후 변화와 구별한다. 기본 결과는 시점·값·지속 길이를 먼저 읽고, 벗어난 정도는 보조 척도로 본다.
- 두 기간 비교와 관계 분석은 현재 비교하는 두 구간을 먼저 보여준다. 직접 입력은 비교 조건에서 조정하고, 운전 비율·상관계수는 결과와 그래프 뒤의 상세에서 확인한다. 조건을 바꾸면 이전 결과를 숨기며, 잘못된 조건에서는 설정을 접어 감추지 않는다.
- 3상 함께 보기는 신호 선택 가까이에 둔다. 전류 수준과 실제 기계적 부하는 구별하며, 3상 전력·불평형은 전류·전압과 불평형을 보는 분석으로 안내한다. 신호 추세 전망은 선택한 하나의 신호값과 입력한 기준까지의 조건부 전망이다. 설비 전체의 건강 상태나 실제 잔여수명을 예측한 것으로 표현하지 않는다.
- 주파수 워터폴에서 선택한 줄은 실제 측정 회차를 유지한다. 마우스·키보드·선택 목록으로 고를 수 있고, A 또는 B 한쪽에 사용하면 그 측정 하나로 해당 기간을 바꿔 재계산한다. 반대 기간은 유지하며, 간격이 있는 기록을 연속 측정 번호로 바꾸지 않는다.

## 관측 현황의 첫 화면

- 설비 한 대는 핵심 변화의 값·시점·실제 추세와 조사 버튼을 중심으로 표시한다. 여러 대는 전체 우선순위 비교표를 유지한다. 등록된 설비 수를 조사할 설비 수로 표현하지 않는다.
- 요약을 읽는 중이거나 실패한 경우에도 신호 기록을 열 수 있다. 로딩·조회 실패·변화를 찾지 못함·분석할 값이 부족함은 구분한다. 실패한 요약은 사용자가 다시 조회할 수 있다.
- 첫 화면의 변화도 설비 요약과 같은 구간·비교값·출처·위치·측정 의미를 사용한다. 다른 신호의 추세로 대신하지 않고, 측정 공백 표시와 조사 링크의 범위를 유지한다. 과거 기록과 변화의 연도는 명시한다.
- 목록 확인 시각과 검토함·운영 상세는 보조 정보로 배치한다. PC에서 변화와 다음 동작을 먼저 읽도록 하고, 좁은 화면은 보조적으로 점검한다.
- 변화가 없는 기록도 마지막 저장값과 실제 기록 추세를 보여준다. 구간 간 연속성을 확인할 수 없으면 점으로 표시하고, 측정 공백을 선으로 잇지 않는다.

## 처음 시작과 핵심 사용 흐름

- 첫 시작은 CSV 파일·이 컴퓨터의 OPC UA 수집 연결·공개 실측 기록 중에서 선택한다. 수집 연결은 해당 입력 영역을 바로 열고, CSV 저장을 마치면 기존 설비 요약과 신호 기록으로 이동한다. 모델 설정은 첫 분석의 필수 단계가 아니다.
- 관측 → 원본 구간 → 기간 비교·관계·주파수 → 신호 전망은 필요에 따라 바로 진입하는 경로다. 모든 단계를 순서대로 완료하게 하지 않는다. 설비·신호·출처·위치·기간을 각 분석이 지원하는 범위에서 유지한다.
- 기록 기준의 변화 탐색과 학습한 모델의 이상 점수는 별도로 사용할 수 있다. 신호 전망은 기본 추세를 먼저 보고 필요할 때 기준값·모델 설정을 조정한다.
- AI 해설과 판단 기록은 선택 사항으로 둔다. 기존 모델 결과·전망의 AI 해설은 그 결과를 설명하며, 기본 측정값이나 변화 표시를 지연시키지 않는다. 저장한 검토는 관측 현황과 검토함에서 다시 열어 이전 판단과 후속 메모를 확인한다.
