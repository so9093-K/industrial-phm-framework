# 관측에서 시작하는 제품 시나리오

2026-11-20 · #737에서 최근 측정 관측·구간 고정·고정 비교 기간·상세 조사·복귀를 구현했다. 입력 연결과 관측 화면은 분리하며, 실제 지속 수집 서버의 존재를 화면 구현의 전제로 삼지 않는다.

메인 화면의 역할은 **실제 측정의 최근 흐름을 보고, 조사할 현상을 선택하는 것**이다. 변화가 없는 동안에도 마지막 값·측정 시각·최근 추이·수신 상태를 확인할 수 있어야 한다. 여기서 ‘변화 없음’은 설비 정상 판정이 아니다.

## 다섯 가지 사용 상황

| 상황 | 처음 보이는 내용 | 사용자 동작과 도달점 |
| --- | --- | --- |
| 지속 관측 | 선택 신호의 마지막 저장값·단위·측정 시각, 최근 추이, 실제 수신 상태 | 최근 흐름을 읽는다. 직접 지정한 기준이 없으면 표시 범위 앞쪽의 관측으로 비교를 시작한다. 분석을 열 필요가 없어도 유용해야 한다. |
| 새로운 변화 | 앞선 관측 또는 사용자가 직접 지정한 기준 대비 변화 구간과 값의 차이·시작·지속 여부 | 구간을 선택해 조사한다. 같은 출처·측정 위치·기간으로 관련 신호를 확인한다. |
| 수신 또는 저장 지연 | 마지막 측정은 남겨 두고 수신 중단·새 값 없음·저장 대기·조회 실패를 구분 | 필요한 연결 상태만 확인한다. 데이터가 끊겼다는 이유로 설비 정지라고 쓰지 않는다. |
| 과거 기록 조사 | 기록 기간 또는 측정 순서, 실제 값과 기록에서 발견한 변화 | 기록의 특정 구간을 조사한다. 벽시계의 현재와 무관하다. 빠른 재생은 기록 위치를 앞당기며 실제 수신으로 표현하지 않는다. |
| 조사 후 관측 복귀 | 조사 중인 대상·구간과 원래 관측 범위 | ‘최근 관측으로’ 돌아간다. 작성 중인 질문·판단은 해당 현상에 남고, 다른 현상과 섞이지 않는다. |

관측은 기존 저장소의 측정 기록을 읽는다. CSV·파일 저장·OPC UA 등 어느 입력 경로인지로 최근 관측의 가능 여부를 제한하지 않는다. 수집 연결 여부와 최근 저장 기록을 따라보는 상태는 구분한다. 같은 설비에도 과거 파일과 수집 중인 출처가 함께 있을 수 있다. 현재 확인한 공기압축기 1306과 베어링 1-1은 모두 저장 기록이다. 실제 수집 출처가 연결되기 전에는 공기압축기를 ‘현재 수신 중’으로 표시하지 않는다. 수명시험 기록을 재생해도 실제 현장 수신과 구분한다.

## 한 번의 조사: 공기압축기 전압 변화

1. 사용자가 선택한 측정 기록의 전압을 관측한다. 기본 범위는 최근 1시간이며 사용자가 바꾼 범위를 유지한다. 새 저장 데이터가 생길 때 최근 구간만 반영한다.
2. 전압 수준이 비교 구간에서 달라지면 같은 그래프에 표시한다. 직접 지정한 기준이 없으면 표시 범위 앞쪽 1/3의 유효 구간(최소 5개)을 비교 기준으로 사용한다. 비교할 후속 측정이 없거나 기준 자료가 부족하면 그 상태를 구별한다.
3. 사용자가 변화 구간을 선택한다. 화면은 그 시점에 고정되고 수집은 계속된다. 들어오는 데이터가 선택 구간이나 A/B 기간을 밀어내지 않는다.
4. 같은 시각의 다른 상전압·전류를 함께 본다. 운전 조건을 맞춰 비교할 자료가 있으면 기존 3상·운전 수준 분석으로 이어간다. 관련 자료가 없으면 없는 범위를 밝힌다.
5. 결과는 ‘어떤 전압이 얼마나 달랐고, 같은 운전 조건에서도 차이가 남는가’로 읽힌다. 전류가 함께 변했는지 등 실제 계산한 사실만 연결한다. 전압 변화만으로 고장 원인을 붙이지 않는다.
6. 더 설명이 필요하면 선택한 현상에 AI 질문을 한다. 모델 점수·전망·판단 기록은 이 조사에 필요한 경우에만 연다. 모든 분석을 거치는 절차를 만들지 않는다.

베어링 과거 기록은 1번에서 ‘저장된 시험 기록’을 연다. 측정 번호와 기록된 간격을 기준으로 진동의 시작·지속·회복을 조사하고, 파형·주파수가 필요한 경우 해당 측정을 연다. 실제 측정 시각이 없으면 현재 날짜로 바꾸지 않는다. 두 모델의 차이를 필수 조사 과제로 삼지 않는다.

## 화면의 역할과 배치

기존 메인 모니터링 안에서 다음 배치를 사용한다. 새 ‘실시간’ 메뉴나 숫자 요약 대시보드를 추가하지 않는다. 첫 화면은 설비 관제이며, 설비를 고르면 그 설비의 조사 화면으로 들어간다. 같은 메인 화면에서 ‘최근 측정’과 ‘기록 변화 조사’를 선택한다. 최근 시각의 측정은 최근 관측으로 시작하고 오래된 기록은 기록 조사로 시작한다. 파일에 추가로 저장된 값도 같은 관측 경로에서 읽는다.

- 첫 화면(설비 관제): 설비마다 한 칸. 지켜보는 신호 묶음의 실제 추이를 기록 전체(수신 중이면 최근 1시간)에 걸쳐 그리고, 찾은 변화 구간을 그 위에 칠한다. 묶음은 변화한 신호와 같은 의미의 다른 상(R·S·T상)이나 같은 통계의 다른 진동 축(수평·수직)이며 같은 단위 눈금에 겹친다. 단위가 다른 신호(전압과 전류)는 겹치지 않는다. 값 줄은 상·축 이름과 마지막 값(포인터를 올리면 그 시각의 값)을 함께 적어 색만으로 구분하지 않는다. 칸 아래에는 마지막 시기의 변화(함께 변한 상·축, 방향, 시작)와 조사 화면으로 가는 링크만 둔다.
- 저장 기록 재생: 관제 화면에서 모든 저장 기록을 같은 비율로 함께 재생한다. 위치까지 구간이 다 지난 측정만 그리고 세로 눈금도 그 측정만으로 정해, 뒤의 큰 값이 앞 시점의 화면에 드러나지 않는다. 변화 판정은 그 위치까지의 기록으로 서버가 계산하며 계산이 끝난 위치를 ‘판정 범위’로 함께 적는다. 판정 기준(기록 앞부분)이 기록과 함께 길어지므로 앞선 판정을 쌓지 않고 가장 최근 판정만 표시하며, 재생 끝은 정지 화면과 같다. 재생 중 조사로 들어가면 같은 위치까지의 기록으로 열리고, 돌아오면 그 위치에 멈춰 있다. 실제 수신으로 표시하지 않는다.
- 조사 화면 위쪽: 설비 선택과 ‘← 전체 설비’. 기록 성격과 실제 수신 상태를 짧게 구분한다.
- 중심: 선택 신호·단위·마지막 측정값과 시각, 넓은 최근 추이 그래프. 마지막 측정값은 구간 선택 후에도 같은 자리에 유지한다. 범위 선택은 항상 그래프 위에 남기고, 선택 구간의 수치와 작업은 그래프 아래에 모은다.
- 그래프 안: 비교 범위와 기준값 점선, 달라진 구간의 시작, 데이터 공백. 기준값이 세로 눈금 밖에 있으면 방향과 값을 표시하며 그래프를 압축하지 않는다. 포인터에는 실제 구간의 시각·평균만 표시하고 공백의 다른 측정으로 대신하지 않는다.
- 그래프 아래: 해당 관측 범위에 관련된 변화의 시작 시각·집계 평균값의 기준 대비 최대 차이·구간 길이를 짧게 표시한다. ‘1분 평균 최대 차이’처럼 실제 집계 간격을 표시하며 원본 측정값의 최댓값과 구분한다. 항목 선택은 그 구간으로 이동한다. 같은 변화의 장문 설명과 카드를 반복하지 않는다.
- 조사 화면: 선택한 신호·구간과 관련 실측 비교가 중심이다. 기존 기간 비교·관계·3상·파형·주파수를 상황에 맞게 사용한다. 메인 그래프를 옆에 계속 붙이지 않는다.
- AI·모델·전망·판단: 필요할 때 실행한다. AI는 이미 확인한 현상을 연결하고 추가로 비교할 대상을 좁히며, 매분 해설을 자동 생성하지 않는다.

선택한 점이나 구간으로 조사를 시작하면 화면이 그 관측에 고정된다. 단순 마우스 올리기는 관측을 멈추지 않는다. 새 데이터는 수집·저장되지만 조사 화면은 자동 이동하지 않는다. ‘최신 측정으로’ 또는 선택 해제·Esc로 최신 범위를 다시 따라간다. 비교 기준으로 지정할 때도 선택을 끝내고 새 기록 확인을 자동으로 재개한다. 저장 기록 화면에는 이 동작 대신 기록 범위 이동을 제공한다.

표시 종료 시각을 고르는 별도 선택 상자는 두지 않는다. 수집 출처는 현재 시각을 기준으로 공백을 유지하며, 오래된 파일 기록은 마지막 측정 시각까지 표시한다. 최근 시각의 파일 측정도 현재 범위에서 볼 수 있다. 입력 경로별로 관측 진입을 제한하지 않는다.

마지막 측정 시각은 값 가까이에 둔다. 마지막 수신·저장 시각은 지연이나 중단을 이해하는 데 필요할 때 표시하고, 처리 시각·내부 버전·원본 지문은 상세로 둔다. 세 가지 시각을 모든 카드에 반복하지 않는다.

## 1분 관측 주기와 데이터 처리

1분은 **새로 저장된 측정에서 실제 값·최근 추이·공백·준비된 변화를 한 번의 관측으로 전달하는 목표 주기**다. 페이지 새로고침만 뜻하지 않는다. 각 관측에서 사용하는 데이터 범위를 맞춰 다음 처리를 수행한다.

`새로 저장된 측정 확인 → 최근 값·추이·공백 갱신 → 해당 범위의 변화 결과 연결 → 관측 화면 반영`

모든 센서의 수집 간격·원본 저장·모델 계산을 1분으로 바꾸지는 않는다. 하나의 관측 주기에 여러 저장 배치를 묶어 읽을 수 있다. 이는 원본의 1분 저장 배치를 도입한 것과 다르며, 후자가 필요한지는 따로 판단한다. 분 단위로 집계해 그릴 때도 마지막 실측과 구간 평균·범위를 구분하고, 짧은 급변을 평균 하나로 지우지 않는다.

- 수집은 센서 시각과 원본을 보존한다. 현재 SQLite 유입 보존과 DuckLake 저장 경로를 재사용한다.
- 화면은 실제 저장이 완료된 범위를 읽는다. 전체 페이지를 재시작하지 않고 바뀐 설비·출처의 값과 최근 추이만 갱신한다. 저장이 늦으면 마지막 확인한 측정을 유지하고 지연을 알린다.
- 변화 결과는 실제 분석한 구간까지만 표시한다. 실측이 먼저 늘고 분석이 뒤따르는 경우 이전 결과를 새 측정의 판단으로 붙이지 않는다. 기준 미설정·자료 부족·차이 미발견을 구분한다.
- 새 데이터 여부는 화면 확인 시각이 아니라 저장 버전과 해당 기록의 변화를 기준으로 판단한다. 늦게 들어온 측정이나 정정으로 과거 구간이 달라지는 경우도 포함한다.
- 새 값이 없다고 선을 연장하거나 같은 값의 측정을 만들어 넣지 않는다. 데이터 변경 시에만 통지하는 출처는 값이 안 바뀌어도 연결이 정상일 수 있다. 중단 판단은 해당 출처의 수신 방식·예상 간격·세션 상태를 따른다.
- 주파수·모델·전망·AI의 실행 주기는 관측 갱신과 별개다. 분석 중인 대상이 바뀌면 그 선택에 맞게 다시 요청하며, 매분 전체 이력을 재계산하지 않는다.

최근 관측은 별도 기준 설정 없이 앞선 유효 관측과 비교를 시작한다. 이 기준은 화면 범위에 따라 바뀌며 정상 판정이나 학습된 현장 감시 기준이 아니다. 화면에는 ‘앞선 관측과 자동 비교’로 구별한다. 직접 고른 구간을 ‘비교 기준으로 사용’으로 지정하면 자동 기준 대신 고정한 기간을 유지한다. 측정 5개 미만인 선택은 기준으로 지정하지 않으며, 기준 지정 후에는 자동으로 새 기록을 확인한다. 출처·위치·신호·단위와 시작·끝을 유지하며 ‘정상 구간’으로 자동 명명하지 않는다. 새 기준을 지정하기 전에도 최신값과 최근 추이는 바로 볼 수 있다. 이 설정을 별도 시작 마법사나 관측의 필수 단계로 만들지 않는다.

## 현재 동작과 확인 범위

- 최근 관측은 기존 측정 이력 API를 사용한다. 마지막 실제 값·단위·시각, 최근 구간의 평균과 최소·최대, 공백을 함께 표시한다. 미세한 구간을 늘려 정상 측정 간격까지 공백으로 만들지 않도록 관측 범위에 맞게 집계한다.
- 한 번의 관측은 기존 저장소의 같은 스냅샷에서 마지막 값과 그래프·비교 기준을 읽는다. 구간을 고르면 실측 신호·기간 비교·신호 관계의 요청에도 같은 스냅샷을 적용한다. 비교에 쓰는 운전 수준·분포·측정 짝과 측정 의미도 같은 버전에서 읽고, 응답이 다른 버전이면 표시하지 않는다. 새로운 데이터베이스나 별도 근거 저장 체계를 만들지 않았다.
- 선택 뒤에는 선택 구간의 평균·측정 수와 후속 조사 동작을 그래프 아래에서 읽는다. 선택·해제 때문에 그래프 위치가 움직이지 않으며 방향키로 측정 선택, Shift+방향키로 구간 확장, Esc로 관측 재개를 지원한다. 원래 관측의 출처·위치·신호·표시 범위·선택 구간은 분석에서 편집하는 신호·A/B 기간과 별도로 보존한다. 분석에서 기간을 바꾸거나 산점도의 점에서 원본 신호로 이동해도 복귀·새로고침 시 원래 관측을 복원한다. 요청한 기록이나 신호가 사라져도 다른 대상으로 대신하지 않는다.
- 실제 공기압축기 저장 기록으로 1440×900·1280×900 화면에서 확인했다. 기간 비교의 B 기간을 편집한 뒤 복귀·새로고침해도 원래 1시간 범위와 선택 구간이 유지됐다. 관계 분석의 신호와 B 기간을 바꾸고 산점도의 점에서 원본 신호를 연 뒤 돌아와도 원래 신호·범위·선택 구간을 복원했다. 세 분석의 실제 요청에도 같은 저장 버전이 전달됐다. 고정 상태의 1분 주기에는 이력 재조회가 없었고, 관측 복귀 후에는 다음 주기에 재조회했다. 저장소 검사는 과거 시각의 측정을 나중에 추가한 뒤 고정한 실측·기간 비교·신호 관계와 운전 수준이 유지되고 최신 조회에만 추가 측정이 반영되는지를 확인한다.
- 후속 조작 개선은 공기압축기 실제 저장 기록으로 1440×900·1280×900 화면에서 확인했다. 별도의 임시 작업공간에서는 명시적인 테스트 CSV에 행을 추가하고 기존 파일 저장 경로를 실행해, 선택 중에는 분 주기에도 관측이 바뀌지 않고 재개 시 새 값이 반영되며 기준 기간이 유지되는지를 확인했다. 분 주기는 브라우저 시간을 진행해 확인하며 현장 수집 검증으로 보고하지 않는다.
- 확인한 공기압축기와 베어링은 과거 기록이다. 새 현장 수집 서버나 새 커넥터를 연결한 결과로 보고하지 않는다. 기존 입력 경로와 저장 자료를 사용했으며, 별도 브라우저 회귀 체계나 시연 런타임은 추가하지 않았다. 기록 재생은 아래처럼 기존 조회 범위를 제한해서 수행한다.

## 저장 기록 빠른 재생과 조사

기록 조사에는 재생·일시정지·위치 이동과 전체 기록 복귀를 제공한다. 전체를 약 20초·1분·2분에 살펴보도록 설정하며, 계산 중에는 다음 장면을 요청하지 않는다. 계산 시간이 더 걸리면 실제 재생 시간도 늘어난다. 긴 센서 간격을 기다리지 않고 변화 전후를 경험하기 위한 기능이며 원본 시각이나 측정 간격을 바꾸지 않는다.

재생 위치는 실제 시간 기록의 `record_until` 또는 진동 측정 번호의 `acquisition_until`로 전달한다. 집계 전의 입력을 제한하며 관련 신호·운전 수준·주파수 지도·전망 학습·AI 질문·저장 검토에도 같은 위치를 적용한다. 앞으로의 실측을 미리 보여주거나 전체 기록으로 예측한 결과를 과거 시점의 전망으로 사용하지 않는다. 이후 원본 정정까지 고정하는 저장소 스냅샷과는 별개 조건이다.

변화를 고르거나 질문·판단을 시작하면 재생을 멈춘다. 계산 중 이전 결과의 조사 버튼은 잠근다. 전력 변화에서는 다른 상전압·전류의 실제 추이를 같은 시간축에서 확인하며, 같은 단위만 같은 세로축으로 겹친다. 진동 변화에서는 같은 A/B 구간의 진동 특징과 주파수 성분을 나란히 읽는다. 원본 파형 비교는 재생을 멈췄을 때 실행한다.

전력·진동 모두 선택한 변화에서 AI에 질문하고 답변을 메모 초안으로 활용할 수 있다. 모델을 묻지 않은 질문에 모델 간 차이를 기본 설명으로 끼워 넣지 않는다. 닫힌 질문 창은 반복 조회하지 않지만 이미 보낸 질문의 접수는 취소하지 않는다. 다시 열면 생성 상태를 조회하고 작성 중인 후속 질문도 유지한다.
