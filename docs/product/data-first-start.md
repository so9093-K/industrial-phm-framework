# 실제 산업 데이터로 시작하기

빈 작업공간의 첫 화면에서는 합성 시연을 실행하지 않습니다. **데이터 연결**에서 실제 측정 파일 또는 수집 소스를 등록한 뒤 기존 분석 화면으로 이동합니다.

## CSV 파일

1. `make up`으로 Operations를 실행하고 `/web/`에서 **데이터 연결**을 엽니다.
2. CSV 파일과 시각 열, 측정값 열, 단위, 설비·측정 지점의 식별 정보를 지정합니다.
3. 파일의 행·시간대·출처·품질을 확인한 뒤 등록하고 수신·이력 저장을 수행합니다.
4. 설비·신호 화면에서 이력·구간 비교·관계·상태 전망을 확인합니다. 모델 없는 이력에서는 기준 구간 이탈을 탐색할 수 있습니다.

파일 등록은 자동으로 고장이나 이상을 판정하지 않습니다. 원본의 의미와 단위는 사용자가 확인해야 합니다.

## OPC UA

**데이터 연결**에서 엔드포인트·NodeId·설비·측정 지점·채널을 등록한 뒤 수신 상태와 저장된 이력을 확인합니다. 접속 오류, 결측, 품질 비트를 실제 관측과 분리해 해석합니다.

## XJTU-SY 실제 베어링 기록

[데이터 안내](../../data/README.md#xjtu-sy)에 따라 원본을 준비한 후:

```bash
uv sync --locked --extra operations
uv run industrial-phm demo xjtu --until 100
```

이 명령은 원본 진동 기록의 일부를 재생하고 Isolation Forest와 LSTM 오토인코더를 연결합니다. 점수·파형·특징·주파수 및 상태 전망은 동일한 제품 화면에서 확인합니다. 실제 고장 확정이나 현장 잔여수명 검증을 뜻하지 않습니다.

## AI-Hub 239 실제 계측

[AI-Hub 데이터 준비](../../data/README.md)를 따라 로컬 아카이브를 준비합니다. CSV/파일 이력 또는 `industrial-phm demo aihub-boiler`의 기록 기반 재생으로 3상 측정·불평형·구간 변화를 분석할 수 있습니다.

어느 경로에서도 데이터가 준비되지 않았다고 합성 측정값으로 대체하지 않습니다. 사용 가능한 측정이 없다면 입력 준비 상태와 이유를 명확하게 표시합니다.
