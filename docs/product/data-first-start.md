# 실제 산업 데이터로 시작하기

빈 작업공간의 첫 화면에서는 합성 시연을 실행하지 않습니다. **데이터 연결**에서 실제 측정 파일 또는 수집 소스를 등록한 뒤 기존 분석 화면으로 이동합니다.

## CSV 파일

1. `make up`으로 Operations를 실행하고 `/web/`에서 **데이터 연결**을 엽니다.
2. CSV 파일과 시각 열, 측정값 열, 단위, 설비·측정 지점의 식별 정보를 지정합니다.
3. 파일의 행·시간대·출처·품질을 확인한 뒤 등록하고 수신·이력 저장을 수행합니다.
4. 등록 완료의 **주요 변화와 측정 상태 보기**에서 설비 요약을 엽니다. 주요 변화의 대표값을 확인하고 변화 직전 비교·관련 신호의 관계로 이어갑니다. 원본 신호와 다른 분석도 선택할 수 있습니다.

파일 등록은 자동으로 고장이나 이상을 판정하지 않습니다. 원본의 의미와 단위는 사용자가 확인해야 합니다.

## OPC UA

**데이터 연결**에서 엔드포인트·NodeId·설비·측정 지점·채널을 등록한 뒤 수신 상태와 저장된 이력을 확인합니다. 접속 오류, 결측, 품질 비트를 실제 관측과 분리해 해석합니다.

## 공개 실측 데이터 (AI-Hub 239·XJTU-SY)

[데이터 안내](../../data/README.md)에 따라 `data/` 폴더에 원본을 준비하면, 빈 작업공간의 첫 화면과 **데이터 연결 › 공개 실측 데이터로 시작**에 가져올 수 있는 기록이 나타납니다. 하나를 고르면 운영 서비스가 백그라운드에서 가져오고, 끝나면 설비 화면으로 이어집니다.

- **AI-Hub 239:** 원천 JSON 하나(설비 하나, 약 한 달)를 저장된 이력으로 넣습니다. 확인된 3상 전압·전류로 부하·불평형과 구간 변화를 분석할 수 있습니다. 원본 시각은 한국 표준시로 가정해 저장합니다.
- **XJTU-SY:** 모델 학습에 쓰지 않은 베어링의 진동 기록을 넣고 Isolation Forest와 LSTM 오토인코더를 연결합니다. 처음 가져올 때 두 모델을 학습용 베어링으로 준비하므로 15개 베어링이 모두 있어야 합니다. 점수·파형·특징·주파수·상태 전망을 같은 화면에서 확인하며, 실제 고장 확정이나 현장 잔여수명 검증을 뜻하지 않습니다.

가져오기 완료는 당시 원본의 지문에 연결됩니다. 준비된 원본의 내용·위치가 바뀌면 완료 표시 대신 다시 가져오기를 제공합니다. 새 내용은 별도 출처로 저장하므로 이전 기록을 덮어쓰지 않습니다. 원본 지문이 없는 이전 가져오기는 완료 여부를 다시 확인해야 합니다.

**XJTU 파형은 원본 CSV를 계속 사용합니다.** 작업공간에는 파일 경로와 SHA-256을 저장하며 파형 파일 자체를 복사하지 않습니다. 가져온 뒤에도 원본을 같은 경로와 내용으로 보관하세요. 이동·삭제·수정하면 기존 기록의 파형 조회와 아직 처리하지 않은 모델 분석이 실패할 수 있습니다. 다시 가져오더라도 이전 파형 파일을 복원하지는 않습니다.

어느 경로에서도 데이터가 준비되지 않았다고 합성 측정값으로 대체하지 않습니다. 사용 가능한 측정이 없다면 입력 준비 상태와 이유를 명확하게 표시합니다.

## 분석 결과 읽기

상태 요약은 저장된 전체 신호를 검토해 주요 변화와 같은 구간의 다른 신호를 보여 줍니다. 대표값은 기준 기간과 변화 구간의 집계 평균 중앙값입니다. 신호명을 선택하면 해당 구간의 원본을 열고, **변화 직전과 비교**나 함께 변한 신호의 **관계 비교**는 선택 신호와 두 기간을 이어받습니다. 계산할 수 없는 신호는 이유를 표시합니다.

분석은 **핵심 결과 → 결과 해석 → 다음 확인** 순서로 읽습니다. 측정 대상과 시간·비교 조건은 결과 옆에 두고, 추가 해석 안내는 펼쳐 볼 수 있습니다. 기간 비교의 조건은 `비교 조건 확인·변경`, 상세 수치·품질은 `기간별 수치와 데이터 품질`에서 확인합니다.

상태 전망은 지원하는 신호·기간으로 첫 추세를 자동 계산합니다. 관리·종료 기준은 **관리·종료 기준 추가 (선택)**, 예측 기간과 학습 설정은 **계산 조건 변경**에서 지정합니다. 입력을 바꾸면 이전 결과를 지우고 다시 계산합니다. 예상 여유는 **기록 마지막 측정부터** 계산하며, 기준값은 사용자가 설비에서 사용하는 값을 입력합니다.

모델이 없어도 저장 신호의 변화를 탐색할 수 있습니다. 반복적인 이상 탐지가 필요할 때 모델 설정을 열어 신호와 기준 기간을 선택하고 학습을 실행합니다. 신호 화면에서 선택한 신호는 모델 만들기의 초기 선택으로 사용합니다.

분석한 모델 결과나 전망에서 **검토 기록에 남기기**를 열면 판단과 선택 메모를 저장하고 검토를 종료할 수 있습니다. **판단 저장**은 기존 검토 기록에 확인을 남기며, 아직 검토 항목이 없으면 해당 결과의 항목을 먼저 만듭니다. 판단을 보류한 항목은 정비 검토함에서 이어서 처리합니다.
