# 0028. Bind forecast and condition outlook to one measurement projection

Status: Accepted (2026-10-16)

Amends: [ADR-0027](0027-condition-and-remaining-life-outlook-from-stored-analyses.md).
ADR-0027의 요청 시 계산·서버 소유 사실·조건부 잔여수명 원칙을 유지하면서,
두 읽기 API의 입력 일치와 이탈 서술의 정확한 의미를 명시합니다.

## Context

`GET /api/v1/forecast`와 `GET /api/v1/outlook`는 같은 저장 신호를 독립적으로
조회하고 계산합니다. 저장 도중 두 조회가 서로 다른 관측을 읽을 수 있습니다.
마지막 획득 번호·관측 시각이 같아도 과거 관측값 또는 원본 구간 평균이 수정될 수
있으므로 마지막 관측만 비교하는 화면 검사는 두 결과의 동일 입력을 보장하지 못합니다.

상태 전망의 기존 `data_version`은 측정값뿐 아니라 이상 탐지 분석 근거까지 포함하는
AI 브리핑의 선택 버전입니다. 미래 예측이 읽지 않는 이상 탐지 데이터를 추가로
비교하도록 결합하면 API 간 불필요한 의존성이 생깁니다.

또한 기준 비교 범위 이탈 시점은 이후 값의 80% 이상이 초기 범위 밖인 첫 위치입니다.
이를 모든 값이 연속으로 이탈한 것으로 표현하지 않습니다. 예측 범위만 도달한
`possible`은 중심 예측의 `expected`와 다른 주장으로 검증합니다.

## Decision

- 측정 시계열을 읽는 서버 경계가 **공통 `measurement_version`**을 소유합니다.
  하나의 (asset, kind, series, source, measurement point)에서 두 API가 실제 사용하는
  시간·유한 측정값의 정규화된 투영을 동일한 순서로 SHA-256 해시합니다.
  시간은 UTC로 정규화하고 값은 부동소수점의 정확한 표현을 사용합니다.
  사용자가 고른 예측 기간·임계값·모델 설정은 이 측정 내용의 정체성이 아닙니다.
- 두 API는 각자 숫자를 서버에서 계산하며, 화면은 신호 식별자·마지막 관측 및
  `measurement_version`이 같은 경우에만 한 쌍으로 보여줍니다.
  불일치하면 재조회하고, 계속 일치하지 않거나 한쪽이 실패하면
  **기존 결과를 최신인 것처럼 다시 보여주지 않습니다.**
- `measurement_version`은 저장소의 트랜잭션 버전, 원본 전체의 체크섬이나
  물리적으로 고정한 snapshot ID가 아닙니다. 동일한 bounded numerical projection을
  확인하는 계약입니다. 원본 근거·수신·분석 provenance의 소유자는 기존 저장소입니다.
- AI 브리핑의 `data_version`은 별도로 유지합니다. 서버가 측정·이상 탐지 근거를
  다시 계산한 뒤 이 버전이 요청의 버전과 일치할 때만 답을 생성합니다.
- `already`, `expected`, `possible`, `beyond`는 독립적인 계산 상태입니다.
  `possible` 도달은 방향에 맞는 예측 범위 상단/하단에서만 가능하다는 제한을
  붙여 표현합니다. 시나리오 차이를 통계적 신뢰구간·고장 확률로 승격하지 않습니다.
- 초기 비교 범위 이탈 시작은 ADR-0027의 '계속 벗어남'이라는
  서술 대신 **이후 값의 80% 이상이 초기 비교 범위 밖**이라는 실제 판정으로
  설명합니다. 반드시 네 시나리오를 채울 필요는 없으며 현재 학습과 중복되는
  최근 구간 시나리오는 생략할 수 있습니다.

## Consequences

- 독립 API의 추가적인 조회 중 재계산 비용은 감수하되, 별도 영속 저장소나
  범용 상태 관리 엔진은 도입하지 않습니다.
- 같은 마지막 관측만 확인하는 테스트 대신 관측 중간값의 변경·동시 갱신·오류 뒤
  resize/화면 복귀·AI 가능 도달 주장 등의 실패를 대표 회귀 테스트로 보호합니다.
- 현재 지원 상태와 정확한 UI 문구는 `docs/status.md` 및 제품 문서에서
  반영하고, 이 ADR의 설계 결정과 일회성 작업 체크리스트를 혼합하지 않습니다.
